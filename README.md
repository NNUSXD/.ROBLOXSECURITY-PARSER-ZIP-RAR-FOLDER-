# Secure Cookie Parser

## Описание
Безопасный парсер cookie файлов из архивов с графическим интерфейсом.

## Требования

### Обязательные библиотеки
```bash
pip install requests
```

### Для полной поддержки архивов (опционально)
```bash
pip install rarfile py7zr libarchive-c
```

### Системные зависимости для GUI
**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**Windows:** Tkinter обычно предустановлен с Python

**macOS:**
```bash
brew install python-tk
```

## Запуск
```bash
python secure_cookie_parser.py
```

## Функции

### Безопасность
- ✅ Извлечение только в защищённую временную директорию
- ✅ Проверка на path traversal атаки
- ✅ Блокировка опасных расширений файлов (.exe, .bat, .sh и др.)
- ✅ Ограничение размера файлов (100MB макс.)
- ✅ Ограничение количества файлов (1000 макс.)
- ✅ Автоматическая очистка после работы
- ✅ Режим ТОЛЬКО ЧТЕНИЕ для извлечённых файлов

### Поддерживаемые форматы архивов
- ZIP (.zip)
- TAR (.tar, .tar.gz, .tar.bz2, .tar.xz)
- RAR (.rar) - требуется `rarfile`
- 7Z (.7z) - требуется `py7zr`

### Парсинг cookie
- Поиск паттерна: `_|WARNING:-DO-NOT-SHARE-THIS.--Sharing-this-will-allow-someone-to-log-in-as-you-and-to-steal-your-ROBUX-and-items.|_...`
- Извлечение до первого пробела
- Подсчёт найденных cookie
- Замер времени выполнения (с точностью до миллисекунд)

### Telegram интеграция (опционально)
- Отправка результатов в Telegram бот
- Отправка файла со всеми найденными cookie
- Форматированный вывод статистики

## Использование

1. Нажмите **"📁 Загрузить"** и выберите архив
2. Если архив запаролен, отметьте **"🔑 Есть пароль?"** и введите пароль
3. (Опционально) Введите Bot ID и Chat ID для отправки в Telegram
4. Нажмите **"▶️ Начать"**
5. Результаты появятся в окне программы

## Примечания по безопасности

⚠️ **Важно:** Программа работает в режиме ТОЛЬКО ЧТЕНИЕ и никогда не исполняет файлы из архива.

🔒 Все извлечённые файлы помещаются во временную директорию с ограниченными правами доступа.

🗑️ После завершения работы временная директория полностью удаляется.
