# ⚡ DREAD PARSER v1.0

**Красивый и мощный парсер .ROBLOSECURITY токенов Roblox**

## 🎨 Особенности

- **Неоновый дизайн** в зелёно-жёлтых тонах
- **Анимированный градиентный фон**
- **Максимальная полнота поиска** токенов
- **Однопоточная обработка** (без многопоточности)
- **Поддержка архивов**: ZIP, RAR, 7Z, TAR, GZ, BZ2
- **Безопасная обработка файлов**
- **Дедупликация кук**
- **Экспорт результатов**

## 🔧 Требования

- Windows 10/11
- .NET 6.0 Runtime
- 7-Zip DLL (для поддержки RAR/7Z)

## 📦 Установка

### Вариант 1: Сборка из исходников

```bash
cd DreadParser
dotnet restore
dotnet build --configuration Release
```

### Вариант 2: Использование готового EXE

1. Скачайте готовый `DreadParser.exe`
2. Положите рядом `7z.dll` (из 7-Zip) для поддержки RAR/7Z
3. Запустите `DreadParser.exe`

## 🚀 Использование

1. Запустите приложение
2. Введите пароль от архива (если есть)
3. Нажмите **"📂 Выбрать Архив"**
4. Выберите архив с файлами
5. Дождитесь завершения обработки
6. Куки будут сохранены в `roblox_cookies.txt`

## ⚙️ Технические детали

### Поддерживаемые форматы архивов:
- `.zip` - DotNetZip
- `.rar` - 7-Zip (требуется 7z.dll)
- `.7z` - 7-Zip (требуется 7z.dll)
- `.tar` - SharpZipLib
- `.gz` - SharpZipLib
- `.bz2` - SharpZipLib

### Паттерны поиска токенов:
1. `WARNING_SIGNATURE` + токен
2. JSON: `"ROBLOSECURITY": "token"`
3. JS: `.ROBLOSECURITY = "token"`
4. Cookie: `.ROBLOSECURITY=token`
5. URL-encoded варианты
6. Сырой поиск base64-строк рядом с ключевыми словами

## 🛡️ Безопасность

Приложение проверяет:
- ✅ Пути извлечения (защита от Zip Slip)
- ✅ Расширения файлов (блокировка .exe, .dll, etc.)
- ✅ MIME-типы (опционально)
- ✅ Символические ссылки
